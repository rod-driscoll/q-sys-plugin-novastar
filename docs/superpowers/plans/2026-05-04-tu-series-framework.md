# NovaStar TU Series + Framework Restructure — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restructure the monolithic `content/novastar.qplug` into the QSC BasicPluginFramework file layout, add NovaStar TU series support, convert IP Address and Model to runtime controls, add a Samsung-style Setup page, refactor the protocol into a packet builder, and add structured debug logging.

**Architecture:** Six Lua source files (`info`, `pages`, `components`, `controls`, `layout`, `runtime`) are concatenated alphabetically by the existing `compile_plugin.sh` script into `plugin.lua`, which `PLUGCC.exe` compiles into `content/novastar.qplug`. All development happens in the source `.lua` files — never edit `plugin.lua` or `novastar.qplug` directly. The TU series uses the same binary packet structure as VX/ProHD (same `55 AA` header, same checksum algorithm) but with source address `0xFC` instead of `0xFE` and TCP port 5201 instead of 5200.

**Tech Stack:** Lua 5.3, Q-SYS Plugin API (TcpSocket, Timer, Controls, Properties), VS Code + PluginCompile toolchain at `..\..\plugincompile\` relative to project root.

- [ ] **Step 4.1: Add buildPacket and hexDump at the top of the if-Controls block**

Insert immediately after `if Controls then`, before the `local NovaStar` table:

```lua
if Controls then
    local VX_SRC, TU_SRC = 0xFE, 0xFC
    local READ, WRITE    = 0x00, 0x01

    local function buildPacket(label, src, dst, devType, port, boardLo, boardHi, code, reg, dataLen, data)
        local bytes = {
            0x00, label, src, dst, devType, port, boardLo, boardHi,
            code, 0x00,
            reg[1], reg[2], reg[3], reg[4],
            dataLen & 0xFF, (dataLen >> 8) & 0xFF
        }
        if data then
            for _, b in ipairs(data) do table.insert(bytes, b) end
        end
        local sum = 0x5555
        for _, b in ipairs(bytes) do sum = sum + b end
        local pkt = {0x55, 0xAA}
        for _, b in ipairs(bytes) do table.insert(pkt, b) end
        table.insert(pkt, sum & 0xFF)
        table.insert(pkt, (sum >> 8) & 0xFF)
        return pkt
    end

    local function hexDump(bytes)
        local s = ""
        for _, b in ipairs(bytes) do s = s .. string.format("%02X ", b) end
        return s
    end
```

```lua
        if ok then
            -- original is the cmd bytes (no preamble, no checksum)
```

```lua
    NovaStar.socket.Data = function()
        local data = NovaStar.socket:Read(NovaStar.socket.BufferLength)
        if DebugRx then
            print("Rx (" .. #data .. "b): " .. hexDump({data:byte(1, #data)}))
        end
        NovaStar.setStatus(0, "Connected - " .. Controls["IPAddress"].String)

        -- Parse TU read responses (response header is AA 55)
        if Controls["Model"].String == "TU" and #data >= 19 then
            local b1, b2 = data:byte(1), data:byte(2)
            if b1 == 0xAA and b2 == 0x55 then
                -- Data byte is at offset 19 (1-based) in the response packet
                local dataByte = data:byte(19)
                if pendingRead == "CurrentSource" then
                    Controls["CURRENT_SOURCE"].String = TU_SOURCE_NAMES[dataByte] or ("Unknown("..dataByte..")")
                    pendingRead = "SystemStatus"
                    sendPacket(TuRead.SystemStatus)
                elseif pendingRead == "SystemStatus" then
                    Controls["SYSTEM_STATUS"].String = TU_STATUS_NAMES[dataByte] or ("Unknown("..dataByte..")")
                    pendingRead = nil
                end
            end
        end
    end
```

```markdown
Q-SYS plugin for NovaStar video wall controllers and TU series meeting boards.

## Building

**Prerequisites:** VS Code with the PluginCompile toolchain installed at `..\..\plugincompile\` relative to this project.

1. Open this folder in VS Code.
2. Press **Ctrl+Shift+B**.
3. Select a version increment: `ver_dev` (patch dev), `ver_fix` (patch), `ver_min` (minor), `ver_maj` (major), or `ver_none` (no change).
4. The compiled plugin is output to `content/novastar.qplug`.

**Never edit `plugin.lua` or `content/novastar.qplug` directly.** Edit the source `.lua` files; `plugin.lua` is a generated concatenation.
```
